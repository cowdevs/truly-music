# truly music

A browser-based YouTube Music player that actually shuffles your playlists properly. Pure, mathematical randomness!
 
## other cool features!

- Listen to your favorite tunes uninterrupted with **ad-free playback**
- Be in control with **global media key support** (play/pause/previous/next)
- **Clean, dynamic UI** (customizability features coming soon!)
- Stay on the move with **background play** on mobile devices

*Feel like a Premium user, without paying a dime!*
